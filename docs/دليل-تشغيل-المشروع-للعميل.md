# 📘 دليل تشغيل مشروع CarCarePlus على جهازك (خطوة بخطوة)

هذا الملف موجّه لك حتى لو ما عندك أي خبرة تقنية سابقة. اتبع الخطوات بالترتيب تمامًا، ولا تتخطى أي خطوة.

## 📂 فكرة عامة عن المشروع (اقرأها قبل ما تبدأ)

المشروع مكوّن من **جزئين منفصلين**، كل واحد فولدر لحاله:

| الجزء | اسمه هنا | وش هو؟ |
|---|---|---|
| **الواجهة الخلفية (Backend)** | `CarCarePlus` | البرنامج اللي يشتغل "خلف الكواليس" — يخزن البيانات ويتعامل مع قاعدة البيانات (مبني بلغة PHP / Laravel) |
| **الواجهة الأمامية (Frontend)** | `CarCarePlus-frontend` | الموقع اللي تشوفه وتتعامل معه بالمتصفح — الأزرار والجداول والشاشات (مبني بـ React) |

**لازم الاثنين يشتغلوا في نفس الوقت** حتى يعمل المشروع بشكل كامل — الواجهة الأمامية وحدها ما راح تعرض بيانات حقيقية لأنها تحتاج تتكلم مع الواجهة الخلفية.

راح تحتاج **نافذتين Terminal (سطر أوامر) مفتوحتين في نفس الوقت** — وحدة للباك اند ووحدة للفرونت اند، وتخليهم شغالين طول فترة استخدامك للمشروع.

---

## 🧰 الخطوة 1 — تثبيت البرامج المطلوبة (مرة وحدة بس)

هذي البرامج لازم تتثبت على جهازك قبل أي شي. أسهل طريقة هي برنامج واحد اسمه **Laragon** يجمع لك أغلب الأدوات المطلوبة بضغطة زر.

### 1.1 تثبيت Laragon (يعطيك PHP + Composer + Git + Node.js بسهولة)

1. روح لهذا الرابط ونزّل النسخة **Laragon Full**:
   `https://laragon.org/download/`
2. شغّل ملف التثبيت واضغط Next على كل الخطوات (الإعدادات الافتراضية تكفي).
3. بعد ما ينتهي التثبيت، افتح برنامج **Laragon**.
4. من داخل البرنامج: اضغط بزر الماوس الأيمن على أي مكان فاضي → **Quick add** → تأكد إن هذي مفعّلة (اضغط عليها لو مو مفعّلة):
   - **PHP** (يجي مفعّل تلقائيًا مع Laragon)
   - **Composer**
   - **Node.js**
   - **Git**
5. اضغط زر **Start** الكبير في البرنامج (هذا يشغّل بعض الخدمات الداخلية لـ Laragon — لسا ما نحتاج نفعّل قاعدة بيانات MySQL، بنستخدم طريقة أبسط بالخطوة الجاية).

> 💡 ليش Laragon بالذات؟ لأنه يثبّت كل شي (PHP, Composer, Node, Git) في مكان واحد ويضبط الإعدادات الداخلية تلقائيًا (شي اسمه PATH) بدون ما تحتاج تفهم التفاصيل التقنية.

### 1.2 التأكد إن كل شي اتثبت صح

1. افتح **Terminal** (تقدر تفتحه من داخل Laragon نفسه: زر **Terminal** في البرنامج — هذا أسهل من cmd العادي لأنه يعرف مكان البرامج تلقائيًا).
2. اكتب كل أمر من هذي واضغط Enter، ولازم يطلع لك رقم إصدار (نسخة) بدون أي خطأ:

```bash
php -v
composer -V
node -v
npm -v
git --version
```

لو أي أمر منهم طلع خطأ (`not recognized` أو ما شتغل) — أعد تشغيل الجهاز مرة وحدة وجرب ثاني، وإذا ما زبط، أعد تثبيت Laragon والتأكد من خطوة **Quick add**.

## 📁 الخطوة 2 — تجهيز مكان المشروع

تأكد إن عندك فولدر واحد رئيسي يحتوي على فولدرين بجنب بعض، بهذا الشكل تقريبًا:

```
مجلد المشروع/
├── CarCarePlus/            ← الواجهة الخلفية (Backend)
└── CarCarePlus-frontend/   ← الواجهة الأمامية (Frontend)
```

لو ما عندك المشروع لسا وتحتاج تنزّله (clone) من Git، افتح Terminal في المكان اللي تبي المشروع يكون فيه واكتب (استبدل الرابط برابط المستودع الفعلي اللي عطوك ياه):

```bash
git clone <رابط-الباك-اند>
git clone <رابط-الفرونت-اند>
```

## ⚙️ الخطوة 3 — تشغيل الواجهة الخلفية (Backend)

### 3.1 افتح Terminal داخل فولدر الباك اند

من Laragon أو من مستكشف الملفات (Windows Explorer): روح لفولدر `CarCarePlus`، اضغط بزر الماوس الأيمن داخل الفولدر واختر **Open in Terminal** (أو "افتح في Terminal").

### 3.2 نفّذ الأوامر التالية **بالترتيب**، وحدة تلو الثانية

```bash
composer install
```
هذا الأمر يحمّل كل المكتبات البرمجية اللي المشروع محتاجها. ياخذ شوي وقت (دقيقة لدقيقتين) — انتظر لين يخلص بدون ما تسكّر النافذة.

```bash
copy .env.example .env
```
هذا يسوي نسخة من ملف الإعدادات (اسمه `.env`) — هذا الملف فيه كل إعدادات المشروع (قاعدة البيانات، المفاتيح، ...). ما تحتاج تعدّل فيه شي دلوقتي.

```bash
php artisan key:generate
```
هذا يولّد "مفتاح أمان" خاص بمشروعك ويحطه تلقائيًا داخل ملف `.env`.

```bash
php artisan migrate --seed
```
هذا الأمر يسوي أهم شيئين مرة وحدة:
1. **ينشئ جداول قاعدة البيانات** (بدون ما تحتاج تثبت أي برنامج قاعدة بيانات — المشروع مضبوط افتراضيًا يستخدم قاعدة بيانات بسيطة على شكل ملف واحد، اسمها **SQLite**).
2. **يحط بيانات تجريبية جاهزة** (حسابات دخول، فروع، خدمات...) حتى تقدر تجرب المشروع فورًا.

   - لو ظهر لك سؤال بالـ Terminal يقول تقريبًا *"database file does not exist, would you like to create it?"* → اكتب `yes` واضغط Enter.
   - لو ما ظهر السؤال وطلع خطأ يقول ما لقى ملف قاعدة البيانات، روح لفولدر `database` داخل `CarCarePlus` وسوّي ملف فاضي جديد باسم بالضبط: `database.sqlite` (بدون أي محتوى بداخله)، وبعدين أعد تنفيذ نفس الأمر `php artisan migrate --seed`.

```bash
php artisan serve
```
هذا يشغّل الباك اند فعليًا. لو كل شي تمام، بتشوف رسالة تقريبًا:

```
Server running on [http://127.0.0.1:8000]
```

**سيب هذي النافذة شغّالة ومفتوحة طول الوقت** — إذا سكّرتها، الباك اند يتوقف عن الشغل.

## 💻 الخطوة 4 — تشغيل الواجهة الأمامية (Frontend)

### 4.1 افتح نافذة Terminal **ثانية جديدة** (بدون ما تسكّر نافذة الباك اند!) داخل فولدر الفرونت اند

روح لفولدر `CarCarePlus-frontend` وافتح فيه Terminal جديد (نفس طريقة الخطوة 3.1).

### 4.2 نفّذ الأوامر التالية بالترتيب

```bash
npm install
```
يحمّل مكتبات الفرونت اند. ياخذ شوي وقت، انتظر لين يخلص.

```bash
copy .env.example .env
```
يسوي نسخة من ملف إعدادات الفرونت اند.

**افتح ملف `.env`** (اللي انسخ حديثًا) بأي برنامج تحرير بسيط (مثل Notepad)، وتأكد إن فيه هذا السطر بالضبط:

```
VITE_API_BASE_URL=http://localhost:8000/api
```

هذا السطر هو **نقطة الربط بين الفرونت والباك اند** — لازم رقم المنفذ (`8000`) يطابق تمامًا الرقم اللي ظهر لك بالخطوة 3.2 لما شغّلت `php artisan serve` (طبيعي يكون 8000 دائمًا إلا لو ظهر لك رقم مختلف).

```bash
npm run dev
```
هذا يشغّل الفرونت اند. بتشوف رسالة تقريبًا:

```
Local:   http://localhost:5173/
```

**سيب هذي النافذة كمان شغّالة ومفتوحة**.

### 4.3 افتح المشروع بالمتصفح

افتح أي متصفح (Chrome مثلاً) وروح للرابط:

```
http://localhost:5173
```

المفروض تشوف صفحة تسجيل الدخول الخاصة بالمشروع. 🎉

## 🔗 كيف يرتبط الفرونت اند بالباك اند؟ (باختصار وبساطة)

فكّر فيها كذا:
- **الباك اند** (`php artisan serve`) = المطبخ اللي يجهّز الطلبات ويخزن كل المعلومات.
- **الفرونت اند** (`npm run dev`) = الصالة اللي تجلس فيها وتشوف القائمة وتطلب.
- سطر `VITE_API_BASE_URL` بملف `.env` بتاع الفرونت = هو "عنوان المطبخ" اللي الصالة ترسل له الطلبات.

فلو يوم من الأيام تغيّر رقم منفذ الباك اند (مثلاً طلع لك `http://127.0.0.1:8001` بدل `8000`)، **لازم تعدّل نفس الرقم** بملف `.env` بتاع الفرونت، وبعدين تسكّر وتعيد تشغيل `npm run dev`.

## 🛠️ حل المشاكل الشائعة

| المشكلة | السبب المحتمل | الحل |
|---|---|---|
| أمر مثل `php` أو `composer` أو `npm` يطلع "غير معروف / not recognized" | البرنامج ما اتثبت صح أو الجهاز محتاج إعادة تشغيل | أعد تشغيل الجهاز، وتأكد من خطوة 1.2 |
| الصفحة بالمتصفح فاضية أو فيها خطأ أحمر | الباك اند مو شغّال | ارجع لنافذة الباك اند وتأكد إنها لسا مفتوحة وتشتغل `php artisan serve` |
| رسالة خطأ فيها كلمة "Network Error" أو "CORS" في المتصفح | رقم المنفذ بملف `.env` بتاع الفرونت ما يطابق رقم الباك اند | راجع قسم "كيف يرتبط الفرونت بالباك اند" فوق |
| رسالة "vendor" أو "class not found" من الباك اند | أمر `composer install` ما اكتمل | ارجع لفولدر `CarCarePlus` ونفّذ `composer install` من جديد |
| الفرونت ما يشتغل ويطلع خطأ عن "module" أو "node_modules" | أمر `npm install` ما اكتمل | ارجع لفولدر `CarCarePlus-frontend` ونفّذ `npm install` من جديد |
| خطأ يتكلم عن قاعدة البيانات (database) | ملف `database.sqlite` مو موجود | راجع الخطوة 3.2 (تشغيل `php artisan migrate --seed`) |
| المنفذ 8000 أو 5173 "مستخدم من برنامج ثاني" (Port already in use) | برنامج ثاني شغّال على نفس الرقم | سكّر البرنامج الثاني، أو شغّل الباك اند برقم مختلف: `php artisan serve --port=8001` — وحدّث `.env` بتاع الفرونت لنفس الرقم |

## ⚠️ ملاحظات مهمة

- **لا تسكّر نوافذ الـ Terminal** طول ما انت تستخدم المشروع — لو سكّرتها المشروع يتوقف عن الشغل بس بياناتك تبقى محفوظة.
- أي تعديل على كود الفرونت اند ينعكس تلقائيًا بالمتصفح فورًا (بدون ما تعيد تشغيل شي).
- أي تعديل على كود الباك اند أحيانًا يحتاج تسكّر نافذة `php artisan serve` وتشغّلها من جديد.
- لو غيّرت أي شي بملف `.env` (أي واحد من الاثنين)، لازم تسكّر وتعيد تشغيل الأمر المرتبط فيه (`php artisan serve` أو `npm run dev`) حتى يقرأ التغيير الجديد.
